# Letty Lilly 22nd Birthday Surprise

A playful mobile-friendly birthday page made for Letty Lilly / Leticia.

Live site: https://miiroxpuganda.github.io/letty-lilly-22-birthday/

Repository: https://github.com/miiroxpuganda/letty-lilly-22-birthday

## What Is Inside

- Personalized English birthday message for Letty Lilly turning 22
- Her photo, birthday hat, balloons, confetti, cake, candles, bunnies, and party decorations
- Animated birthday sequence powered by GSAP
- Tap/click fireworks and automatic celebration bursts
- Background music with a play/pause button
- A cheeky sign-off: "From your Ex Crush"
- Mobile-first layout for sharing on WhatsApp or opening on a phone

## Project Files

- `index.html` - page structure
- `customize.json` - birthday text, name, photo path, music, and font
- `style/style.css` - layout, mobile styling, decorations, and theme
- `script/main.js` - birthday animation timeline
- `script/firework.js` - fireworks and celebration bursts
- `img/` - photo and birthday artwork
- `music/bgMusic.mp3` - background music

## Local Preview

If Node/npm is available:

```bash
npm install
npm run dev
```

The configured dev server uses port `1113`.

Because the site is static, it can also be served by any simple static file server.

## Deploying

This repo is deployed with GitHub Pages from the `main` branch root.

To update the live page:

```bash
git add .
git commit -m "Update birthday site"
git push
```

GitHub Pages will redeploy automatically after the push.
